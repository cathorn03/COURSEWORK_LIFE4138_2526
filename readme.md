#LIFE4138 COURSEWORK

Within this repository is the completed coursework for the LIFE4138 module. It contains 3 directories:

* Notebooks - Contains the completed R and python jupyter notebooks
* Pumpkins_Challenge - Contains the completed pumpkins coding challenge (completed in python).
* Genetics_Challenge - Contains the completed genetics coding challenge (completed in r).

In each directory there is the script for each challenge titled `script.py` or `script.r`. 
Both contain all the outputs from the scripts including the graphs as `.png` files and all text output in a file named `output.txt`. 
Along side these is a `report.qmd` file which contains the write up answering the questions set out by the coursework.
There is also a `requirements.txt` file which contains the list of all packages and modules needed for the scripts.
The outputs of each script are already located in the respective files.
